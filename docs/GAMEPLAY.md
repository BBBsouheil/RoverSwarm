# Missions et commandes

## Démarrage

Sous Windows, double-cliquer sur `JOUER.bat`. Le meilleur modèle V5 est chargé automatiquement. Le briefing permet de sélectionner une mission avec les flèches ou les touches 1 à 3, puis de lancer avec Entrée.

## Missions

### Levé Ares

Cartographier 90 % des cellules accessibles. Le canal radio est nominal et permet le partage de carte à courte portée.

### Zone de silence

Localiser et réactiver deux relais violets, puis atteindre au moins 72 % de couverture. Le canal commence avec une portée de 4 cellules, un délai de 4 pas et 55 % de pertes. Chaque relais rétabli améliore ces trois paramètres jusqu'au régime nominal.

### Réserve critique

Inspecter deux anomalies orange, atteindre au moins 60 % de couverture et conserver un rover actif. Chaque rover ne dispose que de 145 unités d'énergie au départ.

## Commandes

| Touche | Action |
|---|---|
| Espace | Pause ou reprise |
| N | Exécuter un seul pas |
| + / - | Modifier la vitesse |
| R | Générer une nouvelle carte |
| B | Revenir au briefing |
| Tab | Sélectionner le rover suivant |
| G | Changer de vue mémoire/équipe/globale |
| F12 | Enregistrer une capture |
| Échap | Quitter |

Le dernier débriefing est enregistré dans `artifacts/results/last_mission.json`.
